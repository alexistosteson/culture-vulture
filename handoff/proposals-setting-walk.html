One setting to tick

About two minutes. Once, ever.

The weekly run will send you its suggested changes as pull requests, each one a change you accept with one click or turn down. GitHub only lets the site's own automation open them once you allow it. This page walks you through that one tick. It does not let anything merge on its own: every proposal still waits for you.
1 Open the repository's Actions settings: github.com/alexistosteson/culture-vulture/settings/actions. Sign in if GitHub asks.
2 Scroll down to the section headed Workflow permissions. It is near the bottom of the page.
3 Leave the choice above it exactly as it is (it reads Read repository contents and packages permissions). Tick the box below it: Allow GitHub Actions to create and approve pull requests.
4 Click Save at the bottom of that section.
Leave everything else on the page alone. In particular, don't switch the choice above the box to "Read and write". The automation asks for exactly what it needs.
That's it. Tell the session "ticked". It will check the setting from its side and then send a test proposal through.
