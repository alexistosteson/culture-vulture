Your first proposal

About five minutes. This is the check that tells us whether the weekly proposals work for you.

The weekly run now sends its suggested changes as pull requests: a GitHub page that describes one change, which you accept or turn down. Four are waiting from the 12 October week. This page walks you through one of them, Montalvo Arts Center in Saratoga, and asks you one question about it. Whatever you decide is recorded automatically, and nothing reaches the site until a later weekly run uses it.
1 Open the proposal: Start watching Montalvo Arts Center in Saratoga. Sign in if GitHub asks.
2 Read only the description at the top: What changes, Why, What a reader of the site would notice and Evidence. Don't open the Files changed tab; the point is whether the description is enough on its own.
3 The question: could you decide from that description alone, without asking anyone or opening anything else? Tell me yes or no in the chat. If no, say what was missing.
4 Then decide. Both choices are fine, and both are recorded.
  • To accept: scroll to the bottom, click the green Merge pull request, then Confirm merge.
  • To turn it down: scroll to the bottom and click Close pull request. You can add a line in the comment box first saying why; the next run reads it.
Ignore any yellow note saying a workflow is waiting for approval. It is a duplicate of a check that has already passed, and approving it changes nothing.
Done. The page will say Merged or Closed. The other three proposals work the same way: venue-list upkeep, Neck of the Woods and six more towns. You can decide those whenever you like; there is no deadline.
